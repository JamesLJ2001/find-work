# Hot 100 学习站

一个完全离线、无需安装依赖的 LeetCode Hot 100 学习网页。

## 使用方法

直接双击 `index.html`，或把它拖进浏览器打开即可。网站不依赖服务器，搜索、筛选、动画、学习进度、收藏和笔记均可在 `file://` 模式下工作。

学习数据保存在当前浏览器的 `localStorage` 中。换浏览器或清理浏览器数据前，请先使用页面中的“导出数据”；之后可通过“导入数据”恢复。

## 内容原则

- 按力扣 Hot 100 的 17 个类别收录 100 题。
- 每题只推荐一个兼顾面试复杂度、可读性和复用价值的 Python 3 主解。
- 统一讲解结构：一句话本质、识别信号、为什么选、复杂度和易错点。
- 每题配有可播放、暂停、逐步前进和回退的示例轨迹。
- 不复制完整题面；题目标题会链接到力扣官方页面。

## 文件

- `index.html`：页面结构和离线入口
- `styles.css`：全部视觉与响应式样式
- `data.js`：100 题的原创讲解、标签和动画轨迹
- `solutions.js`：统一风格的 Python 3 参考实现
- `app.js`：筛选、详情、动画和学习数据逻辑
- `assets/fonts/`：网页内置的 Fira Code、JetBrains Mono 字体及其许可证
