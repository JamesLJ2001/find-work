# 岗位信息手动追踪表说明

## 文件分层

1. `2027-autumn-openings.md`：当前秋招开放状态和最终投递岗位，使用 UTF-8 Markdown 维护，是后续唯一主记录。
2. `source/target_companies.xlsx`：旧版原始资料，只读保留，不再继续更新，避免再次出现乱码。
3. `target_roles.csv`：岗位总表，从原始表结构化整理，保留完整 JD 描述。
4. `tracker.csv`：投递执行表，只放状态、下一步、简历版本和投递动作。
5. `../data/recruitment_events.csv`：日历提醒数据，由岗位表中的时间节点同步而来。

## 当前策略

秋招正式岗位还没完全开放，所以先用转正实习/同类岗位作为目标公司和目标岗位画像的替代样本。后续秋招 JD 开放后，用同一家公司同一方向的正式秋招岗位替换或补充，不删除原始参考来源。

## 日常规则

1. 每天早上看 Hermes 招聘汇报。
2. 只把高价值岗位录入 `target_roles.csv`。
3. 来源等级必须填 A官方/B聚合/C社区/D未确认。
4. C/D 来源必须回官方验证。
5. 高优岗位状态先设为“待分析JD”。
6. 晚上交给 ChatGPT 的“简历JD招聘工厂”分析。
7. 投递后更新状态、简历版本、内推人、下一步动作。
8. 每晚离开公司前 git commit + push。
