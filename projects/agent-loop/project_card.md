# 项目卡：Agent Loop 工程化改进项目

## 项目背景

金融问答/诊股/选股类问题通常需要多步推理、结构化数据查询、知识检索和结果整合。直接让大模型一次性生成答案容易出现工具误用、参数错误、长上下文失控、无法复盘和难以评测等问题。

## 我的目标

基于可运行的 Agent Loop 基线，构建一个面向金融任务的可观测、可控、可评测执行框架。

## 我负责的模块

1. Agent Loop 执行流程设计
2. 工具注册与参数校验
3. 执行轨迹 trace 记录
4. 异常恢复与兜底策略
5. 离线评测集与指标统计
6. 与金融数据服务/RAG 链路结合

## 技术难点

1. 如何避免 Agent 无限循环
2. 如何让工具调用可校验、可恢复
3. 如何判断一次多步任务是否成功
4. 如何把执行过程沉淀为可复盘日志
5. 如何从 demo 项目变成可写进简历的工程项目
